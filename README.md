###### Clean New Tab

This is a chrome extension which is in development but currently as a html file which shows when you open a new tab instead of default google page

## Features

 Responsive Design 
 Skeomorphism in dark mode and light mode 
 Personalized for you 
 It shows weather info
 Focus System 
 When Chrome Extension is installed you can manage and control your music from there but in html currently cannot
 When Chrome Extension is installed you can see your search history and top sites you visit 

## Performance 
Built to feel fast
-Lightweight 
-Data Process on device except weather one 
-No Unnecessary Animations 


## Privacy
Your New Tab is not a tracking product

Clean New Tab keeps things and data personal except weather one
